# Лабораторная работа # 4

## Обзор проекта

В рамках данного проекта были разработаны и обучены нейросетевые модели для решения двух основных задач обработки естественного языка (NLP):
1.  **Классификация произведений по авторам** (6 и 20 классов) на основе стилистических особенностей текста.
2.  **Анализ тональности** (сентимент-анализ) отзывов об автомобилях Tesla.

Проект включает три исследования (`tf_lite`, `tf_pro`, `tf_ultra_pro`), а также альтернативную реализацию на PyTorch, демонстрирующие различные подходы к токенизации, представлению текста (BoW, Embedding) и архитектуре сетей.

## Модели и результаты

### 1. Lite: Классификация 6 авторов (`home_work\tf\tf_lite.ipynb`)
**Цель:** Распознавание автора по фрагменту текста (Булгаков, Саймак, Фрай, О. Генри, Брэдбери, Стругацкие).

**Методы:**
*   **Bag of Words (BoW):** Простое "мешок слов".
*   **Embedding (GlobalAveragePooling1D):** Векторные представления слов.
*   **Embedding + CNN:** Сверточный слой для извлечения локальных признаков.



### 2. Pro: Сентимент-анализ (Отзывы о Tesla) (`home_work\tf\tf_pro.ipynb`)
**Цель:** Определение тональности (негативный/позитивный) текста отзыва.

**Метод:**
*   Предобработка: Удаление шума и лемматизация (pymorphy3).
*   Векторизация: TF-IDF с N-граммами (1,2).
*   Архитектура: Полносвязная сеть с BatchNormalization и Dropout.



### 3. Ultra Pro: Классификация 20 авторов (`home_work\tf\tf_ultra_pro.ipynb`)
**Цель:** Усложненная задача распознавания стиля 20 различных русских писателей (от Чехова до Шолохова).

**Предобработка:**
*   Балансировка классов (срез до минимального количества образцов).
*   **BoW:** Входные признаки (10000 измерений) -> Dense слои (128/64/20).
*   **Embedding:** Токенизация BPE, Padding до 500 токенов.



### 4. Альтернатива: Реализация на PyTorch (`home_work\pytorch\pytorch_lite.ipynb`)
**Цель:** Демонстрация подхода на фреймворке PyTorch для классификации 6 авторов.

**Архитектура:** Embedding -> GlobalAvgPooling -> Dense (ReLU) -> Softmax.

**Результат:** Стабильное обучение (~55% accuracy на тесте при 15 эпохах, визуализация графиков потерь и точности).
